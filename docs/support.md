# Yapper support

Yapper is free, private voice dictation for iPhone. Speech is transcribed on your iPhone; nothing is sent anywhere.

## Getting started

1. Open Yapper and allow the microphone.
2. Settings › General › Keyboard › Keyboards › Add New Keyboard › Yapper, then turn on Allow Full Access.
3. In any app, switch to the Yapper keyboard with the globe key and tap the mic. The first time, Yapper opens and
   starts listening; talk, tap Done, then swipe right along the bottom edge to go back. Your words are typed in.
4. The speech engine then stays on for the time you choose (15 minutes by default), so the next dictations happen
   right in the keyboard.

## Common questions

- **Why does the keyboard open the Yapper app?** iOS doesn't let keyboards use the microphone, so the app does the
  listening. It only has to open once per session.
- **Why is it slow to start the first time?** The first time a model loads, iOS optimizes it for your iPhone's chip,
  which can take a few minutes. After that it loads in seconds.
- **Why the orange dot?** iOS shows it whenever an app has the microphone on. Turn the engine off in the app, the
  keyboard or the Dynamic Island to make it go away.
- **The keyboard only types, it won't dictate.** Turn on Allow Full Access for Yapper in Settings › General ›
  Keyboard › Keyboards › Yapper.
