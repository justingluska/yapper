# Security policy

Yapper is built so that nothing you say leaves your iPhone. If you find something that breaks that promise, or any
other security or privacy problem, please tell us privately first.

## Reporting a vulnerability

Email **team@goldpenguin.org** with:

- what you found and why it matters,
- steps to reproduce (iPhone model, iOS version, Yapper version or commit),
- any proof of concept.

Please don't open a public issue for security reports. We'll reply within a few days, keep you posted on the fix, and
credit you if you'd like.

## What we most want to hear about

- Any network request other than the model download the user starts.
- Audio or text leaving the device, or being readable by other apps.
- The keyboard exposing what you type or dictate outside Yapper's own App Group.
- Model files loaded from anywhere other than the pinned Hugging Face revisions.

## Supported versions

Only the latest release and the `main` branch get security fixes.
